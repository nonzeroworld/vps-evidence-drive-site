VPS Evidence Drive

VPS Evidence Drive is a privately operated tool for transferring selected evidence files from a virtual private server (VPS) to the owner's Google Drive account.

The tool is designed to preserve development and research evidence, including approved reports, test results, manifests, and related artifacts.

How it works

The tool uses rclone and the Google Drive API to:

  • Upload explicitly selected evidence files to Google Drive.
  • Organize evidence by project, task, source revision, and verification run.
  • Download selected evidence back to the VPS for recovery testing.
  • Verify file integrity using file sizes and SHA-256 checksums.

Google Drive permissions

VPS Evidence Drive requests the drive.file OAuth scope.

This permission allows the application to create, read, modify, and delete files that it creates or that the user explicitly makes available to the application. It does not grant unrestricted access to the user's entire Google Drive.

Private operation

VPS Evidence Drive is intended for the owner's private infrastructure. It is not a public file-sharing service and does not offer registration or accounts to external users.

Google OAuth credentials are stored privately on the VPS and are not published on this website.
